## 새로운 고급 전략 (1-19번)

### 🚀 전략 #1: 고급 통합 전략 (Advanced Multi-Factor System)

**개요:**
- Multi-Factor Scoring + Hybrid Strategy 통합
- 거래량, 모멘텀, 평균회귀, 변동성 복합 필터링
- 동적 트레일링 스톱 적용

**매수 조건:**
```
✅ 거래량: 5일 평균 대비 1.5배 이상 (관심도 증가)
✅ 모멘텀: 5일선 > 20일선 (상승 추세 확인)
✅ 평균회귀 방어: 종가가 20일선 대비 5% 이내 (과열 방지)
✅ 변동성 제한: 전일 대비 ±3% 이내 (급등락주 제외)
✅ 가격 범위: 5,000원 ~ 500,000원 (저가주/고가주 제외)
✅ 선정 기준: (거래량 비율) × (모멘텀 강도) 상위 10개
```

**매도 조건 (동적 트레일링):**
```
수익 구간별 차등 적용:
- 10% 이상 수익: 5% 역행 시 매도 (수익 보호)
- 5-10% 수익: 3% 역행 시 매도
- 0-5% 수익: -2% 손절
- 손실 구간: -3% 손절
- 익절 목표: 15% 달성 시 전량 매도
```

**자본 설정:**
```
초기 자본: 10,000,000원
매수 금액: 1,000,000원/종목
최소 예수금: 2,000,000원
최대 포지션: 10개
```

**백테스트 기간:** 2023-01-02 ~ 현재

**추천 대상:**
- 공격적 투자 성향
- 스윙 트레이딩 (3-10일 보유)
- 중형주 선호

**실행 방법:**
```bash
python simulator_v2.py
# 입력: 1, y
```

**매수:** 5일선이 20일선을 상향 돌파
**매도:** 익절 +5% / 손절 -2%
**자본:** 10,000,000원 / 매수 500,000원

## 백테스팅 실행 방법

### 1. 시뮬레이션 실행

```bash
python simulator_v2.py
```

**입력값:**
- 시뮬레이팅 할 알고리즘 번호: `1-36` 중 선택
- 초기화 여부: `y` (처음) / `n` (이어서)

### 2. 결과 확인

```sql
USE simulator1;  -- 전략 번호에 따라 변경 (simulator21, simulator22 등)

-- 최종 수익 확인
SELECT * FROM jango_data ORDER BY date DESC LIMIT 1;

-- 매매 내역
SELECT * FROM all_item_db WHERE sell_date != 0 ORDER BY sell_date DESC;

-- 수익률 계산
SELECT
    COUNT(*) as total_trades,
    SUM(CASE WHEN sell_rate > 0 THEN 1 ELSE 0 END) as wins,
    AVG(sell_rate) as avg_return,
    MAX(sell_rate) as max_return,
    MIN(sell_rate) as min_return
FROM all_item_db
WHERE sell_date != 0;
```
