### 1-3. 매수 조건 — baseline_v2 전문 (`library/value_strategy_e.py`)

```sql
SELECT a.*,
       ROUND((a.vol120 + 0.0) * a.close / 100000000, 1) AS liq_cap_100m
FROM `{date_str}` a        -- daily_buy_list DB의 날짜 테이블
WHERE
    -- ① 유동시총 필터 (vol120*close >= 300억)
    --    소형주·조작주 차단, 일평균 거래대금 대용치
    (a.vol120 + 0.0) * a.close >= 30000000000

    -- ② 단기 거래량 급증 배제
    --    모멘텀 피크 진입 방지 (vol20 <= vol120 × 2.5)
    AND a.vol20 <= a.vol120 * 2.5

    -- ③ 3단 정배열 (close > clo20 > clo60 > clo120)
    --    중기 추세 확인
    AND a.close > a.clo20
    AND a.clo20 > a.clo60
    AND a.clo60 > a.clo120

    -- ④ DMI 방향성 (plus_di > minus_di)
    --    추세 방향 확인
    AND a.plus_di > a.minus_di

    -- ⑤ 고변동성 소형주 제거 (atr14 / close <= 6%)
    --    일간 변동폭이 가격의 6% 초과 시 제외
    AND a.atr14 <= a.close * 0.06

    -- ⑥ 투자주의 (fix_date = 해제일)
    AND NOT EXISTS (
        SELECT 1 FROM stock_invest_caution c
        WHERE c.code = a.code
          AND c.post_date <= '{date_fmt}'
          AND c.fix_date  >= '{date_fmt}'
    )

    -- ⑦ 투자경고 (cleared_date = 실제 해제일, NULL = 현재 지정 중)
    AND NOT EXISTS (
        SELECT 1 FROM stock_invest_warning w
        WHERE w.code = a.code
          AND w.post_date <= '{date_fmt}'
          AND (w.cleared_date IS NULL OR w.cleared_date >= '{date_fmt}')
    )

    -- ⑧ 투자위험
    AND NOT EXISTS (
        SELECT 1 FROM stock_invest_danger d
        WHERE d.code = a.code
          AND d.post_date <= '{date_fmt}'
          AND (d.cleared_date IS NULL OR d.cleared_date >= '{date_fmt}')
    )

    -- ⑨ 관리·KONEX 제외 (날짜 컬럼 없음 — 현재 등록 전체)
    AND NOT EXISTS (SELECT 1 FROM stock_managing m WHERE m.code = a.code)
    AND NOT EXISTS (SELECT 1 FROM stock_konex    k WHERE k.code = a.code)

-- 유동시총 내림차순 (대형주 우선)
ORDER BY (a.vol120 + 0.0) * a.close DESC
LIMIT 5   -- e_max_positions
```

**baseline_v1 → baseline_v2 변경 사항 (4가지)**

| # | v1 | v2 |
|---|---|---|
| 크기 필터 | `vol20 × close ≥ 100억` | `vol120 × close ≥ 300억` |
| 거래량 급증 | 없음 | `vol20 ≤ vol120 × 2.5` (신규) |
| 변동성 필터 | 없음 | `atr14 ≤ close × 6%` (신규) |
| 정렬 기준 | `clo120 모멘텀` | `vol120 × close DESC` (유동시총 대형 우선) |

## 4. 확정 근거 요약

1. **MDD 일관성**: MA120은 하락장/급락+반등/하락장/강세장 4개 국면에서 MDD가 
   -16.04 ~ -17.76%로 수렴(σ=0.78%). OFF·MA60은 σ≈11%로 국면에 따라 10배 이상 편차.

2. **2020 의존성 제거**: MA60의 합성 우위를 설명하는 단 하나의 연도(V자 반등)를 
   제거하면 MA120이 구조적으로 우월.

3. **손실 제한**: 유일한 손실 연도(2022년)에서 -12.99%로 KOSPI(-25.50%)의 절반. 
   Gate OFF는 -45.27%.

## 6. 원래 목표와의 차이

### 원래 목표
**급등 없이 계단식으로 조용히 우상향하는 대형 안정주**를 포착하는 기술적 패턴 전략.  
예시 종목: 삼성전자·신한지주·KB금융·한화에어로스페이스·HD현대중공업·SK스퀘어.  
*(재무 지표 수치(ROE≥XX% 등)로 정의된 기준은 없었다 — 가격·거래량·지표 기반 패턴 선별이 본래 의도였다.)*

### 실제 결과
**고유동성 대형주 추세추종 + MA120 레짐 필터** 시스템.

### 차이의 근거

1. **회귀 테스트 통과종목**: 삼성전자(246일), 한화에어로스페이스(236일),  
   HD현대중공업(169일), SK스퀘어(167일) — 전형적인 추세 대형주.

2. **신한지주·KB금융의 경계성**: 두 종목이 회귀 테스트를 통과한 것은 해당 기간에  
   우연히 3단 정배열 + DMI를 동시에 만족했기 때문. 일반적으로는 조건 경계에 있음.

3. **`vol120 × close ≥ 300억` 조건의 효과**: 이 조건이 실질적으로 대형 추세주를  
   강하게 편향시킨다. "조용한 우상향"보다 "거래대금 상위 추세주"에 가까운 선별이 된다.

4. **결론**: 원래 의도(조용한 계단식 우상향)와 실제 동작(대형 추세추종)의 괴리를  
   인지하고 운영해야 한다. 성과 자체는 나쁘지 않으나, 포지션 성격이 다르다.
