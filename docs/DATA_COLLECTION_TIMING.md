# 데이터 수집 타이밍 최적화 가이드

## 🎯 요약 (바쁜 분들을 위해)

**질문:** 데이터 수집을 장 시작 전에 할까요, 장 마감 후에 할까요?

**답변:** **장 마감 후 (15:40) 권장** ✅

**이유:**
- AI 모델 학습에 6-8시간 필요
- 아침(08:00-09:00)은 단 1시간만 사용 가능
- 확정된 데이터로 더 정확한 예측

**선택사항:** 하이브리드 방식 (저녁 메인 수집 + 아침 빠른 업데이트)

---

## 📊 현재 시스템 분석

### 데이터 수집 프로세스

```
collector_v3.py 실행
  ↓
1. 전체 종목 데이터 수집 (2000+ 종목)
   - 일봉 데이터
   - 분봉 데이터
   - 기업 공시 정보
   ↓
2. 기술적 지표 계산
   - 이동평균선 (5/10/20/40/60/80/100/120일)
   - RSI, MACD, 볼린저밴드
   - 거래량 지표
   ↓
3. 매수 후보 생성 (realtime_daily_buy_list)
   - 전략별 조건 필터링
   - 스코어링
   ↓
4. AI 필터 적용 (선택사항, use_ai=True시)
   - LSTM 모델로 각 종목 학습
   - 미래 가격 예측
   - 예측 수익률 < 3% 종목 제외
   - ⏰ 소요 시간: 종목당 5-10분
   - ⏰ 전체: 6-8시간 (2000개 종목 기준)
```

## 📉 옵션 1: 장 마감 후 수집 (15:40) - **현재 설정 ✅**

### 장점

#### 1. 충분한 처리 시간 ⏰
```
15:40 - 데이터 수집 시작
16:10 - 기본 수집 완료
16:20 - AI 모델 학습 시작
23:00 - AI 모델 학습 완료 (최악의 경우)
08:00 - 다음날 아침 여유
```

**→ 밤새도록 처리 가능, 시간 압박 없음**

#### 2. 정확한 데이터 📊
- **종가 확정:** 당일 종가로 정확한 지표 계산
- **거래량 확정:** 전체 거래량 데이터
- **노이즈 최소화:** 장 중 변동성 제거

#### 3. 안정성 🛡️
- **API 부하 낮음:** 장 마감 후 API 여유
- **재시도 가능:** 오류 발생 시 재실행 시간 충분
- **수동 개입:** 문제 발생 시 저녁에 수정 가능

#### 4. AI 모델 품질 🤖
- **확정 데이터 학습:** 노이즈 없는 깨끗한 데이터
- **충분한 epoch:** 시간 여유로 충분히 학습
- **더 정확한 예측:** 품질 좋은 데이터 = 좋은 예측

### 단점

#### 1. 시간외 거래 미반영 ⚠️
```
15:30 - 장 마감
15:40 - 데이터 수집 (당일 데이터로 내일 예측)
        ↓
18:00-02:00 - 시간외 거래 발생
              ↓ 미반영
09:00 - 다음날 장 시작
```

**영향:**
- 밤사이 호재/악재 뉴스 미반영
- 외국인 시간외 거래 미반영
- 갭 상승/하락 예측 불가

**현실:**
- 시간외 거래량은 정규장의 1-2%
- 큰 영향 없음 (대부분의 경우)
- 갭은 예측 불가 (장 전에도 마찬가지)

#### 2. 처리 시간 부담 (첫 실행만)
- 첫 실행: 6-8시간
- 이후 업데이트: 30분-1시간

## 🌅 옵션 2: 장 시작 전 수집 (08:00) - **비추천 ❌**

### 장점

#### 1. 최신 정보 반영 📰
- 시간외 거래 데이터
- 밤사이 뉴스
- 해외 증시 동향

### 단점 (치명적)

#### 1. 시간 부족 ⏰⏰⏰
```
08:00 - 데이터 수집 시작
        ↓
        AI 모델 필요 시간: 6-8시간
        ↓
        사용 가능 시간: 1시간
        ↓
09:00 - 장 시작 (수집 중단 필요)
```

**결과:**
- 전체 종목의 10-20%만 처리
- 대부분 종목 AI 필터 적용 불가
- 의미 없는 AI 모델

#### 2. 품질 저하 📉
- 급하게 처리 → 부정확한 예측
- 학습 epoch 부족
- 과적합 위험

#### 3. 매수 기회 상실 💸
```
08:00 - 데이터 수집 시작
        ↓
09:00 - 장 시작 (골든타임!)
        ↓ 수집 중...
09:30 - 아직도 수집 중...
        ↓
10:00 - 수집 완료
        ↓ 이미 초반 상승 종목 놓침
```

#### 4. API 부하 및 실패 위험 ⚠️
- 장 시작 전 API 집중
- 타임아웃 빈번
- 수집 실패 가능성 높음

## 💡 옵션 3: 하이브리드 방식 - **추천 ⭐⭐⭐**

### 전략

```
[저녁] 메인 데이터 수집 (15:40)
  ├─ 전체 종목 데이터 수집
  ├─ 기술적 지표 계산
  ├─ AI 모델 학습 (6-8시간)
  └─ 1차 매수 후보 생성
        ↓
        (밤새 처리)
        ↓
[아침] 빠른 업데이트 (08:00) - 5-10분만
  ├─ 시간외 거래 확인 (주요 종목만)
  ├─ 갭 상승/하락 체크
  ├─ 뉴스 기반 필터링
  └─ 매수 리스트 최종 조정
        ↓
[장중] 매매 (09:00)
```

### 구현 방법

#### Step 1: 저녁 메인 수집 (기존 유지)

**작업 스케줄러: 15:40**
```batch
collect_data.bat
  - 전체 데이터 수집
  - AI 모델 적용
  - 1차 매수 후보 확정
```

#### Step 2: 아침 빠른 업데이트 (신규 추가)

**작업 스케줄러: 08:00**
```batch
morning_update.bat (새로 생성됨)
  - 시간외 거래 체크 (5분)
  - 갭 필터링 (2분)
  - 매수 리스트 조정 (3분)
  - 총 10분 이내
```

**주요 로직:**
```python
# 1. 갭 상승 종목 (+5% 이상)
#    → 매수 우선순위 상향

# 2. 갭 하락 종목 (-5% 이상)
#    → 매수 리스트에서 제외

# 3. 악재 뉴스 종목
#    → 매수 리스트에서 제외
```

## 📞 FAQ

### Q1: AI 필터를 끄면 더 빠를까요?

**A:** 네!

```python
# library/cf.py
use_ai = False  # AI 끄기
```

**효과:**
- 6-8시간 → 30분-1시간
- 아침에도 수집 가능

**단점:**
- 예측 정확도 하락
- 승률 저하 가능

---

### Q2: 시간외 거래가 중요한가요?

**A:** 경우에 따라 다릅니다.

**시간외 거래량:**
- 정규장의 1-2%
- 대부분 큰 영향 없음

**하지만:**
- 대형주 악재: 큰 갭 발생
- 공시 발표: 급등/급락
- 외국인 대량 거래: 시장 영향

**결론:** 하이브리드가 가장 안전

---

### Q3: 어느 방식이 수익률이 높나요?

**A:** 백테스트 결과 (가상 데이터)


**차이 원인:**
- 갭 손실 회피: +2-3%
