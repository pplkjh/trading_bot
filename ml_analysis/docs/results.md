## 1. 콘솔 출력 읽기

### Pearson 상관계수 테이블

```
  타겟 [win] 과의 Pearson 상관계수  (Top 25)
  =================================================================
  피처                             r        해석
  -------------------------------------------------------
  score_f                      +0.1823   ★★★ 유의미 ↑수익
  bb_position                  +0.1541   ★★★ 유의미 ↑수익
  inst_buy_ratio               +0.1203   ★★  중간    ↑수익
  d1_diff_rate                 -0.1876   ★★★ 유의미 ↓수익   ← 역상관
  composite_score              +0.0823   ★★  중간    ↑수익
  foreign_buy_ratio            +0.0614   ★   약함    ↑수익
  adx                          +0.0312   ★   약함    ↑수익
  obv                          -0.0041       미미    ↓수익
```

**해석 기준**

| r 절댓값 | 등급 | 의미 |
|---|---|---|
| 0.15 이상 | ★★★ 유의미 | 이 피처는 수익과 명확한 관계가 있음 |
| 0.08~0.15 | ★★ 중간 | 어느 정도 관계 있음 |
| 0.04~0.08 | ★ 약함 | 미약한 관계 |
| 0.04 미만 | 미미 | 거의 관계 없음 (노이즈 수준) |

**부호의 의미**

- `+`: 값이 클수록 수익 날 확률 높음
- `-`: 값이 클수록 수익 날 확률 낮음 (역상관 → 패널티로 전환 검토)

> 예: `d1_diff_rate` r = -0.18 → "당일 등락률 클수록 다음날 수익 낮다"  
> → v3.3에서 `breakout_score`를 패널티로 전환한 실제 근거

### Walk-Forward CV 결과

```
  CatBoost-binary  교차검증 요약
  =================================================================
  AUC      : 0.5823  ±0.0241
  Accuracy : 0.6102  ±0.0187
```

**AUC 해석**

| AUC | 의미 |
|---|---|
| 0.50 | 랜덤과 동일 (신호 없음) |
| 0.52~0.55 | 약한 신호. 트랜잭션 비용 커버 불가 수준 |
| 0.55~0.62 | **실질적 신호 존재**. 주식 ML에서 충분히 의미 있음 |
| 0.62~0.70 | 강한 신호. 스코어 구조가 매우 효과적 |
| 0.70 이상 | 과적합 의심 (또는 look-ahead bias) |

## 2. 차트 읽기

### `corr_*.png` — 상관계수 막대그래프

- 초록색 막대: 양의 상관 (값 높을수록 수익 ↑)
- 빨간색 막대: 역상관 (값 높을수록 수익 ↓)
- 주황 점선(±0.08), 빨간 점선(±0.15): 유의미성 기준선
- **점선을 넘는 피처 = 스코어 개선 1순위 후보**

### `score_dist_*.png` — 스코어 구간별 분포

상단: 승률(%), 하단: 평균 수익률(%)

```
이상적 형태: composite_score 높을수록 승률 단조 증가
문제 형태:  특정 구간에서 승률 오히려 하락 → 역U자 형태 (고점 진입 현상)
```

> v3.4 이전에 150pt+ 구간에서 승률이 낮아지는 현상이 관찰됐음.  
> 현재 v3.4+inst_flow에서는 score_a 역U자 패널티 제거 후 해소.

### `heatmap_*.png` — 컴포넌트 간 상관 히트맵

- 비대각선이 0.7 이상: 두 피처가 겹침 (다중공선성)
- `composite_score`와 `score_a`가 0.8 이상 → 동시에 모델에 넣을 필요 없음
- `sell_rate` 행/열: 각 컴포넌트와 수익률의 선형 상관

### `importance_*.png` — 피처 중요도

- 막대가 길수록 중요
- 초록(상위) → 빨강(하위) 그라데이션
- **여러 모델에서 공통으로 상위인 피처 = 신뢰도 높은 신호**

### `importance_cmp_*.png` — 모델 간 비교 (grouped bar)

```
모든 모델에서 높음   → 강한 신호 (전략 개선 1순위)
CatBoost만 높고 LASSO는 0 → 비선형 효과만 있는 피처
LASSO만 높음       → 단순 선형 관계만 존재
모든 모델에서 낮음  → 제거 고려
```

### `shap_bee_*.png` — SHAP Beeswarm

각 점 = 하나의 거래.

- X축: SHAP 값 (양수 = win 예측 강화, 음수 = loss 쪽으로 기여)
- 색상: 피처 값의 크기 (빨강=높음, 파랑=낮음)
- Y축: 전역 중요도 내림차순 (위가 더 중요)

```
inst_buy_ratio  [파란 점들이 왼쪽, 빨간 점들이 오른쪽]
→ inst_buy_ratio 높을수록(기관이 많이 산 날) win 확률 높음
→ inst_buy_ratio 낮거나 없을 때(0 또는 NaN) win 확률 낮음
```

### `shap_bar_*.png` — SHAP Bar Plot

`|SHAP 값|` 평균. `importance_*.png`보다 "예측 기여도"를 직접 측정하므로 더 신뢰도 높음.

## 4. 결과를 스코어 개선에 활용하는 법

### Step 1: 교차 검증으로 강한 신호 선별

아래 3가지 모두 통과하는 피처를 찾는다:

1. `corr_*.csv`: |r| ≥ 0.08 이상
2. `importance_catboost_*.csv`: 상위 10위 이내
3. `perm_importance_*.csv`: 양수

### Step 2: 현재 스코어에 없는 피처 발견

ML에서 중요한데 `score_a~g`에 아직 반영되지 않은 피처 → 신규 컴포넌트 후보.

### Step 3: 역상관 피처 확인

| 피처 | r < 0 | 현재 스코어 내 역할 | 조치 |
|---|---|---|---|
| `d1_diff_rate` | -0.18 | 구 v3.3 score_a에 양수 기여 | → v3.4에서 패널티로 전환 ✅ |
| (새 피처) | r < -0.08 | 현재 양수 점수로 보상 중 | → 패널티로 전환 검토 |

### Step 4: LASSO가 0으로 만든 피처 처리

`importance = 0.0`이면 해당 스코어 컴포넌트 비중 축소 또는 auto_reject 조건으로 이동 검토.

### inst_flow(score_g) 특별 해석

```
inst_buy_ratio가 다음 조건 충족 시 score_g 비중 유지/강화 근거:
  1. Pearson r ≥ 0.05 (score_component_analysis 결과)
  2. perm_importance > 0 (ml_analysis 결과)
  3. feature_discovery에서도 중요도 높음 (교차 검증)

어느 하나라도 실패하면:
  → score_g 0pt (비활성화) 또는 5~10pt로 축소 검토
```

## 5. 분석 결과 활용 주의사항

1. **하나의 실행 결과만으로 결론 내리지 말 것**  
   동일 파라미터로 3회 이상 실행해 안정성 확인

2. **AUC ≠ 실전 수익률**  
   AUC 0.58이라도 실전 수익 가능, AUC 0.62라도 실전 손실 가능

3. **Strategy B 결과는 참고 수준**  
   ~200건은 통계적으로 불충분. 실전 데이터 1,000건 이상 쌓인 후 재분석 권장

4. **피처 추가/제거는 백테스트로 최종 검증**  
   ML 분석은 "후보 선별" 역할. 실제 적용은 `score_analyze.py` 백테스트로 확인

5. **`feature_discovery`와 교차 검증**  
   ml_analysis 결과는 선택 편향이 있음.  
   중요한 피처라면 `feature_discovery`에서도 같은 결론이 나와야 함.
